# DRIFTER（schwung-drifter）

Ableton Move 上の Schwung で動く、2 VCO のモノフォニック・クロスモジュレーション・シンセです（Schwung の sound generator モジュール）。

> REON driftbox SIII に着想を得たモジュールです。
> REON とは無関係で、REON の承認も受けていません。

REON が公開している機能一覧と一般的な DSP 技術だけをもとに、ゼロから書いた実装（クリーンルーム実装）です。REON 製品のファームウェア・コード・回路は一切使っていません。

---

## 概要

目指しているのは「よくある 2 オシレーターのシンセ」ではなく、REON driftbox らしさの再現です。

- 2 つの VCO がオーディオレートでお互いを変調し合い、金属的な音・ノイズのような音・カオティックな音まで暴れる
- 共振（レゾナンス）付きのラダー・フィルターを、VCO や LFO でオーディオレート変調する
- ジョイスティック（DRIFT）でピッチ・フィルター・ディレイを揺らしながら演奏する

そのため、現代的なシンセ機能は**意図的に入れていません**。ADSR、フィルター・エンベロープ、ベロシティ、ポリフォニー、ユニゾン、コーラス、リバーブ、シーケンサー、ウェーブテーブル、マクロ、プリセット・ブラウザはありません。ノートはゲートを開けるだけです。（例外として、音作りのきっかけ用にノブをまとめてランダムにする RANDOM パッドだけは付けています。）

## 機能

- VCO × 2、それぞれ 5 波形（0.3 Hz〜14 kHz：LFO の速さから可聴域まで）
- VCO1 ⇄ VCO2 のオーディオレート・クロス FM（1 サンプル単位）。深さは VCO ごとに独立
- VCO ごとの FM / SYNC 切り替え（相手の VCO へのハードシンク）
- ミキサー（VCO1 / VCO2 の音量）
- **SUB**：VCO1 の 1 オクターブ下のサイン波。フィルターの後ろで足すので、低音の土台が痩せない
- 24 dB/oct の非線形ラダー・ローパス・フィルター（ゼロディレイ・フィードバック型）。自己発振する
- VCF への変調：VCO1 / VCO2 / LFO をそれぞれ ON/OFF、深さは共通の 1 本（オーディオレート）
- LFO（三角波 / 矩形波、0.02〜200 Hz）。VCO1・VCO2・VCF へそれぞれ ON/OFF
- ディレイ：TIME と FEEDBACK だけ。時間がなめらかに追従し、繰り返しが暗くなり、フィードバックは柔らかく飽和する
- DRIFT X / Y（ジョイスティック相当）と、それぞれの行き先の切り替え
- Gate Hold（Off / Play / Always）と Trigger
- RANDOM パッド：ノブをまとめてランダムに（音が確実に出る範囲で）
- 出力はモノラル（左右同じ）

## 使い方（はじめての操作）

### 1. スロットに読み込む

1. Schwung の画面を開き、使いたいトラックのスロットを選びます。
2. Sound Generator の一覧から **DRIFTER** を選びます。
3. Move でそのトラックを選び、パッドを押すと音が出ます。

**旧名「Driftbox SIII」（ID `driftbox`）から改名しました（v0.5.0）。** 内部 ID も `drifter` に変わったため、Move からは別のモジュールとして見えます。旧版を入れていたセットでは、スロットに DRIFTER を入れ直してください（旧版のノブ設定とオートメーションは引き継がれません）。

モジュールを入れた直後（インストール・更新の直後）は、**必ず Move を再起動**してから使ってください。再起動しないと、古いモジュールと新しいモジュールが混ざった状態になり、ノブが効かないなどの不具合が起きます。

### 2. 音を出す方法

| 方法 | 鳴り方 |
|---|---|
| パッドやクリップのノート | 押している間（ノートの長さの間）だけ鳴る |
| **Gate Hold = Play**（初期値） | Move が再生している間ずっと鳴り、停止すると止まる |
| Gate Hold = Always | 停止中も鳴り続ける（ドローン） |
| Trigger | 押すと 0.2 秒だけ鳴る |

Gate Hold は SETUP 2 ページ（4 ページ目）のノブ 5、Trigger は同じページのノブ 6 です。
初期値は Play なので、Move の再生ボタンを押すだけで鳴り始め、停止で止まります。ノートを弾いたときだけ鳴らしたいときは Gate Hold を Off にします。どのモードでも、ノートを弾けば鳴り、そのノートの音程になります。

### 3. まず触ってみるノブ

ノブは「DRIFT → 音源 → フィルター」の順に並んでいて、演奏中に触るものは最初の 2 ページ（MAIN と MIX/VCF）にまとめてあります。3・4 ページ目（SETUP 1 / SETUP 2）は、波形や切り替えスイッチなど一度決めたら触らない設定です。

**MAIN（1 ページ目）**
1. **ノブ 1（VOLUME）**：全体の音量です。
2. **ノブ 2・3（DRFT X / DRFT Y）**：ジョイスティックです。初期状態では X が 2 つの VCO の音程、Y がフィルターのカットオフを動かします（下の「DRIFT で演奏する」参照）。
3. **ノブ 4・6（V1 FRQ / V2 FRQ）**：2 つの VCO の音程です。V2 FRQ を動かすと、変調の質感もガラッと変わります。
4. **ノブ 5（V1 MOD）**：VCO2 で VCO1 を変調します。少し回すと音が硬く・金属的になり、たくさん回すとノイズのように崩れます。ノブ 7（V2 MOD）は逆向き（VCO1 で VCO2 を変調）です。
5. **ノブ 8（SUB）**：低音の補強です（下の「低音を出す」参照）。

**MIX/VCF（2 ページ目）**
1. **ノブ 1・2（V1 VOL / V2 VOL）**：2 つの VCO の音量バランスです。
2. **ノブ 3（CUTOFF）とノブ 4（RESO）**：フィルターです。RESO を右いっぱい近くまで回すとフィルターが自分で発振し、ピーという音が加わります。
3. **ノブ 5（VCF MD）**：VCO や LFO でフィルターを揺らす深さです（何で揺らすかは SETUP 2 で選びます）。
4. **ノブ 6（RATE）**：LFO の速さです。
5. **ノブ 7（D.TIME）とノブ 8（F.B）**：ディレイの長さと量です。F.B が 0 だとディレイなし、上げるとエコーが入り、右いっぱいでは音が飽和しながら繰り返し続けます。D.TIME を回すとエコーの音程がテープのように揺れます。

### 4. 低音を出す

VCO の波形だけでは低音が足りないときのために、**SUB（MAIN のノブ 8）** があります。

- VCO1 の 1 オクターブ下で鳴るサイン波です。音程は VCO1 の FREQ ノブ・弾いたノート・DRIFT X に従い、**FM はかかりません**。VCO が FM で暴れていても、低音は安定して鳴ります。
- **フィルターの後ろ**で足すので、カットオフを閉じても、レゾナンスを上げても痩せません（ラダー・フィルターはレゾナンスを上げるほど低音が減る性質があります）。
- 初期値は 50 %。右に回すほど低音が太くなります。上げすぎると、上の倍音が出力段の飽和で押されて音がこもるので、耳で加減してください。
- もっと低くしたいときは、V1 FRQ（MAIN のノブ 4）を下げるか、低いオクターブを弾きます。FREQ は表示の約 6.5 % で 1 オクターブ動きます。

### 5. ハードシンクの音を出す

1. SETUP 1 ページ（3 ページ目）のノブ 6（V2 F/S）を **Sync** にします。VCO2 が VCO1 に同期します。
2. MIX/VCF ページのノブ 1（V1 VOL）を下げ、ノブ 2（V2 VOL）を上げます（同期された VCO2 を聴くため）。
3. MAIN ページのノブ 6（V2 FRQ）を回します。音程は VCO1 のまま、倍音だけが「ギュイーン」と変わります。

VCO2 の周波数が VCO1 より高いほど効果がはっきり出ます。Sync 中も MOD ノブの FM は効くので、MAIN ページのノブ 7（V2 MOD）を回すとさらに複雑になります。VCO1 側（SETUP 1 のノブ 4）を Sync にすると、今度は VCO1 が VCO2 に同期します。

### 6. RANDOM パッドで音を作る

DRIFTER の画面を開いている間、**右上のパッドが RANDOM**（光ります）になります。押すたびに、ノブがまとめて新しいランダムな値になります。画面上部には一瞬「RANDOM」と出ます。

- **変わらないノブ**：VOLUME、GATE HOLD、DRIFT X / Y と X TGT / Y TGT、SUB（と TRIGGER）。音量・鳴り方・ジョイスティックの役割・低音の量は、押しても変わりません。
- **それ以外のノブはすべて変わります**。VCO の周波数・変調・波形・FM/SYNC・音量、フィルター、LFO、ディレイ、変調スイッチです。
- 範囲は「音が確実に出る」ように絞っています。VCO は C4 で 40 Hz〜1.2 kHz（LFO の速さまでは下げない）、VCO1 の音量は 50 % 以上、カットオフは閉じ切らない（約 380 Hz 以上）、レゾナンスは自己発振の手前まで、FM と VCF MOD はノイズになる手前まで、F.B は鳴り続けるウォッシュの手前までです。ノイズ波形を 2 つの VCO に同時に選ぶことはなく、2 つ同時に Sync にもしません。
- Move の Record をオンにしたまま押すと、ランダムな値への変化がオートメーションとして記録されます。

**画面を開いている間、ほかの 31 個のパッドは何もしません**（光りません）。Schwung の仕組み上、モジュールはパッドを 1 つだけ借りることができず、32 個まとめて借りる必要があるためです。そのため、DRIFTER の画面を開いたままパッドで音程を弾くことはできません。画面を閉じると、パッドは普通の音程入力に戻ります。

### 7. DRIFT（ジョイスティック）で演奏する

MAIN ページのノブ 2（DRFT X）とノブ 3（DRFT Y）が、実機のジョイスティックに相当します（−1〜+1、真ん中が 0）。それぞれの行き先は SETUP 1 ページのノブ 1（X TGT）とノブ 2（Y TGT）で切り替えます。

- **DRFT X**：X TGT が VCO なら 2 つの VCO の音程を ±3 オクターブ、D.Tm ならディレイ時間を 1/4 倍〜4 倍に動かします。
- **DRFT Y**：Y TGT が VCF ならカットオフを ±5 オクターブ、F.B ならディレイのフィードバックを ±0.6 動かします。

普通のパラメーターなので、下の「オートメーション」で動きを記録できます。

## 操作方法（詳細）

### パラメーター・ページ

Schwung 標準のノブ画面と同じ画面で操作します（`ui_chain.js` が Schwung 自身のページエンジンで描いています。違いはパッドを使うことだけです）。ジョグで 4 ページを切り替えます（MAIN → MIX/VCF → SETUP 1 → SETUP 2）。

| ページ | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
|---|---|---|---|---|---|---|---|---|
| **MAIN** | VOLUME | DRIFT X | DRIFT Y | VCO1 FREQ | VCO1 MOD | VCO2 FREQ | VCO2 MOD | SUB |
| **MIX/VCF** | VCO1 VOL | VCO2 VOL | CUTOFF | RESO | VCF MOD | LFO RATE | D.TIME | F.B |
| **SETUP 1** | X TARGET | Y TARGET | VCO1 WAVE | VCO1 FM/SYNC | VCO2 WAVE | VCO2 FM/SYNC | LFO→VCO1 | LFO→VCO2 |
| **SETUP 2** | VCO1→VCF | VCO2→VCF | LFO→VCF | LFO WAVE | GATE HOLD | TRIGGER | – | – |

並びは信号の流れと同じ「DRIFT → 音源 → フィルター（→ ディレイ）」です。演奏中に回すノブ（MAIN・MIX/VCF）を前に、一度決めたら触らない設定（行き先・波形・モード・変調スイッチ・Gate Hold）を後ろの SETUP 1・SETUP 2 に置いています。

TRIGGER はクリックするか、ノブを少し回すと発火します（値を持たない「ボタン」です）。

### 各パラメーター

| キー | 範囲 | 内容 |
|---|---|---|
| `vco1_freq`, `vco2_freq` | 0〜1 | 周波数。0.3 Hz〜14 kHz の対数カーブで、**MIDI ノート 60（C4）を弾いたときの周波数**。ほかのノートはそこから 12 ノートで 1 オクターブ動きます（CV 入力と同じ考え方）。初期値は VCO1 ≒ C4（262 Hz）、VCO2 はその 1 オクターブ下 |
| `vco1_mod`, `vco2_mod` | 0〜1 | その VCO への変調の深さ。相手の VCO（常に）と、LFO（スイッチが ON のとき）の両方にかかります。二乗カーブで、1 のとき変調源 1 あたり ±6 オクターブの指数 FM |
| `vco1_wave`, `vco2_wave` | Saw / Tri / Sqr / Puls / Nois | 波形（**暫定の 5 種類**、下の「実機で確認できなかった点」参照）。Puls はデューティ 20 % |
| `vco1_mode`, `vco2_mode` | FM / Sync | Sync にすると、その VCO が相手の VCO にハードシンクします。Sync 中も MOD の FM は効きます |
| `vco1_lfo`, `vco2_lfo` | Off / On | LFO をその VCO の MOD に入れる |
| `vco1_vol`, `vco2_vol` | 0〜1 | ミキサーの音量 |
| `vcf_cut` | 0〜1 | カットオフ 16 Hz〜約 17.6 kHz（対数） |
| `vcf_reso` | 0〜1 | レゾナンス。約 0.91 より上で自己発振します |
| `vcf_mod` | 0〜1 | VCF への 3 つの変調源に共通の深さ（二乗カーブ、1 で ±6 オクターブ） |
| `vcf_vco1`, `vcf_vco2`, `vcf_lfo` | Off / On | VCF の変調源。オーディオレートで足し合わされます |
| `lfo_rate` | 0〜1 | 0.02〜200 Hz（対数） |
| `lfo_wave` | Tri / Sqr | LFO の波形 |
| `delay_time` | 0〜1 | 10 ms〜1 s（対数）。約 80 ms でなめらかに追従します |
| `delay_feedback` | 0〜1 | 0 ならディレイなし。上げるとエコーとその繰り返しが増え、右いっぱいでは飽和しながら鳴り続けます |
| `drift_x`, `drift_y` | −1〜+1 | ジョイスティックの X / Y |
| `drift_x_target` | VCO / D.Tm | X の行き先 |
| `drift_y_target` | VCF / F.B | Y の行き先 |
| `gate_hold` | Off / Play / Always | **Play（初期値）**：Move の再生中はゲートを開けっぱなし、停止で閉じる（ディレイの残響だけ残る）。**Always**：常に開けっぱなし（ドローン）。**Off**：ノートの間だけ。ノートと Trigger はどのモードでも鳴ります |
| `trigger` | （ボタン） | ゲートを 0.2 秒開く |
| `volume` | 0〜1 | 出力音量（x^1.5 カーブ、なめらかに追従、0 で完全な無音） |
| `sub` | 0〜1 | VCO1 の 1 オクターブ下のサイン波の量（初期値 0.5）。FM の影響を受けず、フィルターの後ろで足されます |

この 30 個のキー名は固定です（`sub` は v0.6.0 で追加）。セットやチェーンの保存データはこの名前で値を覚えています。

### ノートの扱い

- モノフォニック、**後着優先**（最後に押したノートが鳴る）。新しいノートを離すと、まだ押している中で一番新しいノートに戻ります。全部離すとゲートが閉じます。
- ベロシティは使いません。ピッチベンドもありません。
- エンベロープはありません。ゲートが VCA を直接開閉し、クリック防止のために約 3 ms だけなめらかにしています。
- CC 120 / 123（All Sound Off / All Notes Off）でゲートを閉じます。

### DRIFT の動き

- **X → VCO**：両方の VCO を ±1 で ±3 オクターブ（オクターブ単位で直線）。
- **X → D.TIME**：−1 で 1/4 倍、+1 で 4 倍のディレイ時間。時間は追従するので、X を動かすとエコーの音程がテープや BBD ディレイのように揺れます。
- **Y → VCF**：カットオフを ±5 オクターブ。
- **Y → F.B**：FEEDBACK ノブの値に ±0.6 を足します（0〜1 に収まります）。

### オートメーション（Move の録音で動きを記録する）

Schwung 本体のオートメーション機能で、ノブの動きを Move のクリップに記録・再生できます（Schwung 1.6 以降）。モジュール側の特別な設定はいりません。

**記録する**
1. Move で DRIFTER のトラックを選び、クリップを再生します。
2. Move の **Record** を押して録音状態にします。
3. Schwung の DRIFTER の画面でノブを回します。回した動きがそのクリップに記録されます。
4. Record を止めます。以後、クリップがループするたびに記録した動きが再生されます。

**消す**

| 範囲 | 操作 |
|---|---|
| 1 つのノブだけ（今のクリップ） | ノブ画面で **Delete を押したまま、そのノブに触る（少し回す）** |
| 1 ステップだけ | ステップを押さえたまま Delete を押し、ノブに触る（ノブに触らずに離すとそのステップの全パラメーター） |
| トラック全部 | そのスロットの **Slot Settings → Clear Lanes** |

**うまく効かないとき**
- **再生中なのにオートメーションが聞こえない／ノブを回した値に貼り付く**：Schwung の**シーン**（Shift+Vol+Step3 の Scenes 画面）で、そのパラメーターがスナップショットにロックされていないか確認してください。Schwung は「ノブ → オートメーション → シーン → LFO」の順に値を決めるため、シーンにロックされたパラメーターはオートメーションより後のシーン側の値が鳴ります。Scenes 画面でスナップショットを編集状態にし、Delete を押したままノブを回すとロックが外れます。
- **ノブを回しても音が変わらない**：モジュールを更新したあと Move を再起動していない可能性があります。再起動してください。
- 画面上のノブの針は**ノブ本来の値**を指したままで、オートメーションの値は別の小さな印で表示されます。針が動かないのは正常です。

## 信号の流れ

```
                       LFO
                ┌──────┼──────┐
                ↓      ↓      ↓
              VCO1    VCO2    VCF
                ↕ FM / SYNC ↕
                └──┬───┘
                  MIX
                   ↓
                  VCF  ← VCO1 / VCO2 / LFO × VCF MOD（オーディオレート）
                   ↓
                  ＋ SUB（VCO1 の 1 オクターブ下のサイン波、FM なし）
                   ↓
                  VCA  ← ゲート（ノート / GATE HOLD / TRIGGER）、約 3 ms のなめらかさ
                   ↓
                 DELAY （TIME, FEEDBACK）
                   ↓
                 VOLUME → 出力（モノラル）
```

VCO・ミキサー・VCF はホストの 2 倍（88.2 kHz）で計算し、31 タップのハーフバンド・フィルターで 1 回だけ間引きます。VCA・ディレイ・出力は 44.1 kHz です。クロス FM は相手の VCO の**1 サンプル前**の出力を使うので、どちらの VCO を先に計算しても結果は同じです。

## ビルド

必要なもの：`gcc`、`python3`、Move 用には `aarch64-linux-gnu-gcc`。
Schwung のプラグイン API ヘッダー（`third_party/schwung/host/plugin_api_v1.h`、Schwung 1.7.3 からそのまま）を同梱しているので、このリポジトリだけでビルドできます。

```bash
scripts/build.sh arm64      # dist/drifter/dsp.so と dist/drifter-module.tar.gz
scripts/build.sh native     # テスト用のデスクトップ版 dsp.so
scripts/test.sh             # 全テスト + ARM64 ビルド（--quick で 60 秒のストレステストを省略）
```

`scripts/check_abi.py` は、ARM 版の `.so` が AArch64 でない・Move の glibc 2.34 より新しい関数を使っている・`move_plugin_init_v2` 以外を公開している、のどれかに当たるとビルドを失敗させます。

## Schwung との互換性

- プラグイン API **v2**（`move_plugin_init_v2`）。マルチインスタンス（6 個分の固定プール、オーディオスレッドでのメモリ確保なし）。ホストは 44.1 kHz（22.05〜96 kHz も可）。
- すべての入り口はオーディオ（SPI）コールバック上で呼ばれるため、DSP の中ではメモリ確保・ファイル入出力・ロック・スレッド・ログを一切行いません。
- 状態の保存：`{"v":2,"p":[29 個の値]}`（TRIGGER 以外の全パラメーター）。すべての値が正しく範囲内のときだけ読み込みます。v0.5.0 以前の `{"v":1,...}`（SUB なしの 28 個）も読み込め、SUB は初期値になります。
- 選択肢のあるパラメーターは番号で値を返し、番号でも選択肢名でも受け付けます。
- 再生状態はホストの拍位置（`get_beat_position`、停止中は負）で判断し、ない場合は MIDI クロック（Start / Stop）で判断します。
- Schwung 1.7.3 で動作を確認しています。

## Signal Chain

`component_type: "sound_generator"`、`chainable: true`。30 個すべてのパラメーターを `chain_params` で公開しているので、チェーン・ノブ画面・LFO の行き先・オートメーションのどこからでも操作できます。

Schwung は、無音が続いたスロットを休止させて CPU を節約します（休止中は約 0.5 秒おきにしか計算しません）。MIDI ノートが来ればすぐに起きますが、ノブ画面からの TRIGGER や GATE HOLD の変更は起こしてくれません。そこで、パラメーターを変えてから 30 秒間は、無音のブロックに −75 dBFS の小さな直流（聞こえない）を出してスロットを起こしておきます。GATE HOLD が Play のときは、再生開始の頭から鳴らすために、無音のあいだずっとこれを出し続けます（停止中も通常どおりの CPU を使います）。

## 実機との違い

- デジタル実装なので、VCO がドリフトしません。アナログのノイズもありません。
- CV / ゲート / オーディオ入力はありません。MIDI ノートを CV とゲートの代わりにしています（ノート 60 を中心に 12 ノートで 1 オクターブ）。ピッチベンドもありません。
- DRIFT ジョイスティックは 2 つのノブです。手を離しても中央に戻りません。
- ハードシンクは帯域制限していません。クロス FM も 2 倍オーバーサンプリングまでなので、深い FM やシンクでは多少エイリアスが出ます（Move の CPU を優先しています）。
- VCF は入力段に tanh を 1 つ置いた TPT ラダーです。トランジスタ・ラダーの飽和の近似で、回路そのもののモデルではありません。
- TRIGGER は 0.2 秒固定です（パラメーターの書き込みには「離す」がないため）。
- ディレイの音量は FEEDBACK と連動しています（0 でディレイなし）。SIII に独立したディレイ音量つまみがあるという資料が見つからなかったためです。
- 変調の深さの考え方は推定です。VCOx MOD は相手の VCO と LFO（ON のとき）の**両方**の深さなので、VCO に LFO のビブラートをかけると、必ず相手の VCO の FM も少しかかります。
- GATE HOLD の Play は Move 用に足したモードです（実機には Move の再生という概念がないため）。
- SUB も Move 用に足した機能です。実機にはサブオシレーターがありません（Move のスピーカーやヘッドホンでも低音の土台が出るように加えました）。

## 実機で確認できなかった点

調べた資料：REON の SIII 製品ページ、implant4 の REON ページ、minet の driftbox S ページ、販売店の掲載情報。
**SIII について確認できたこと**：VCO ごとに 5 波形（ノイズを含む）、FM とオシレーター・シンク、VCO1・VCO2・VCF を変調できる LFO、ジョイスティックで時間とフィードバックを操作できるディレイ。
以下はすべて**実装上の仮定**です（マニュアルや実機で確認できたら差し替える予定）。

| 項目 | このモジュールでの仮定 | 根拠 | 変える場所 |
|---|---|---|---|
| 5 つの波形 | Saw、Tri、Square、Pulse 20 %、Noise | 「ノイズを含む 5 種類」しか公開されていない | `dsp/oscillator.h`（`DB_WAVE_1..5`）、`module.json` の選択肢 |
| FM/SYNC の主従 | 各 VCO のスイッチで相手の VCO にシンク（対称） | 公開されていない | `db_engine_init` の `mod_source[]` |
| SYNC 中の MOD | FM も効く（シンク + FM） | 公開されていない | `db_engine_render` |
| VCF の回路 | 24 dB/oct の非線形ラダー | driftbox S rev.2 の「24dB/oct ラダータイプ」（SSM2044 とする資料もある） | `dsp/filter.h` |
| LFO の波形 | 三角波、矩形波 | 公開されていない | `db_engine_render` |
| VCO への LFO の深さ | その VCO の MOD ノブ | 公開されていない | `db_engine_render` |
| VCO の範囲 | 0.3 Hz〜14 kHz | driftbox S の仕様 | `DB_VCO_LO_HZ` / `DB_VCO_HI_HZ` |
| ディレイの方式と時間 | デジタル、10 ms〜1 s、BBD 風に暗くなる | 公開されていない | `dsp/delay.h`、`DB_DELAY_*` |
| DRIFT の範囲 | X：±3 oct / ×1/4〜×4、Y：±5 oct / ±0.6 | 公開されていない | `db_engine.h` の `DB_DRIFT_*` |
| Gate Hold | ゲートを開けっぱなしにする | 公開されていない | `db_engine_render` |
